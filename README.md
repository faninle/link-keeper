# لینک‌های من (LinkKeeper)

اپ اندروید برای ذخیره لینک‌ها با توضیحات، گروه‌بندی، جستجو و رمز ورود. (Kotlin + Jetpack Compose)

## ساخت APK با GitHub Actions
1. یک مخزن جدید در GitHub بساز و کل محتوای این پوشه (شامل پوشه `.github`) را در شاخه `main` پوش کن.
2. در تب **Actions** ورک‌فلو **Build APK** اجرا می‌شود (یا دستی با Run workflow).
3. بعد از پایان، از پایین صفحه اجرا، آرتیفکت **LinkKeeper-apk** را دانلود کن و `app-debug.apk` را روی گوشی نصب کن.
4. برای انتشار روی بخش Releases یک تگ بزن: `git tag v1.0 && git push origin v1.0`

## نکته‌ها
- کلید امضای `app/debug.keystore` ثابت است تا نسخه‌های بعدی روی نسخه قبلی نصب شوند.
- رمز عبور فقط به‌صورت هش (PBKDF2) در گوشی ذخیره می‌شود. بازیابی ندارد؛ اگر فراموش شد باید داده‌های اپ را پاک کنی.
